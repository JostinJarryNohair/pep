# P.E.P prêt à porter - Website Rebrand

A modern, elegant website rebrand for P.E.P prêt à porter, a clothing store with a rich heritage dating back to 1946.

## Features

- Responsive design that works on all devices
- Modern, elegant aesthetic with soft color palette
- Gradient backgrounds and color transitions
- Clean, minimal navigation
- Elegant typography with italics for emphasis
- Interactive elements with smooth animations
- Complete information architecture preserving all original content

## Technologies Used

- HTML5
- CSS3 (with modern features like CSS Grid, Flexbox, and CSS Variables)
- Vanilla JavaScript (no frameworks or libraries required)
- Google Fonts (Playfair Display and Poppins)
- Font Awesome icons

## Pages/Sections

1. **Home** - Featuring hero section, featured products, about section, services, custom tailoring, and contact information
2. **Navigation** - Links to all main sections: Accueil, Boutique, À Propos, Nos services, Corporatif, Sur mesure, Nos collections, Contact

## Design Highlights

- Soft color palette with pastel colors (pink, purple, beige/cream)
- Gradient backgrounds and color transitions
- Organic blob shapes as decorative elements
- Elegant typography with italics for emphasis
- Coral/pink accent color for highlights
- Frame-like elements for images

## How to Use

Simply open the `index.html` file in a web browser to view the website locally. All assets are included and no server is required.
